## 一、启动与关闭

### 启动

```powershell
cd D:\dsh\mori-pet
.\node_modules\electron\dist\electron.exe .
```

GPU 参数已固化在代码里（`app.disableHardwareAcceleration()`，等价 `--disable-gpu`），**不用再传**。
`--no-sandbox` 也写进了 `app.commandLine`，但 Chromium 的沙箱在 JS 之前初始化，受限环境（DSH 沙箱、部分 CI）里仍需命令行传入：

```powershell
.\node_modules\electron\dist\electron.exe . --no-sandbox
```

> 普通桌面双击快捷方式不需要任何参数。

### 数据目录

启动时按顺序试这几个位置，**建目录 + 写探针文件都成功**才采用（`initUserData()`）：

1. `MORI_DATA_DIR` 环境变量（便携/测试用）
2. `%APPDATA%\mori-pet`
3. `%LOCALAPPDATA%\mori-pet`
4. **程序旁 `.userdata`**：开发态 = 仓库根目录，打包后 = exe 同级目录（便携模式）
5. `%TEMP%\mori-pet`

| 内容 | 位置 |
|---|---|
`settings.json`（引导完成标记 / 开机自启 / 尺寸 / 透明度 / 节能模式） | 上述目录 |
`window.json`（位置/尺寸/透明度）+ Electron 缓存 | 上述目录 |
日志 `pet.log` | 优先程序目录；不可写时落到上述目录 |
旧版 `.userdata\window.json` | 首次运行自动迁移，原文件保留 |

> 配置损坏时自动改名为 `settings.json.bad` 并回落到默认值，不会导致起不来。

> `%APPDATA%` 不可写时（受限沙箱/只读配置）自动退回程序目录 `.userdata`，启动不受影响；启动时 stderr 会打印 `[boot] userData = …`。
> 需要便携模式可用环境变量 `MORI_DATA_DIR` 指定数据目录。

## 三、参数怎么调

### 3.1 台词

文件：`src\lines.js`

```js
window.LINES = {
  head: [...],   // 摸头
  ears: [...],   // 摸耳朵
  body: [...],   // 戳身体
  tail: [...],   // 拽尾巴
  summon: [...], // 召唤
  idle: [...],   // 待机
  menu: [...],   // 菜单点播
  eat: [...],    // 喂食
  deep: [...],   // 慎用池（深夜/久置）
  story: [...]   // 封存池（只能手动）
};
```

**注意**

- 加台词直接往数组里加字符串即可，无需改代码
- 「我讨厌你」这类**对天狐大人说的**台词**不要**放进任何池
- 仿写台词请在行尾注释 `// 仿写`

### 3.2 眩晕

文件：`src\app.js`

| 常量 | 位置 | 说明 |
|---|---|---|
`DIZZY_DUR` | `app.js` 顶部附近 | 菜单触发的眩晕时长（秒） |
`PIN_ARMS` | `app.js` | 眩晕期间钉回 0 的参数名 |

### 3.3 甩飞阈值

文件：`electron\main.js` → `ipcMain.on('drag-by')`

```js
FLING_ENTER = 1500     // 250ms 窗口均速（px/s）才进入
FLING_EXIT = 1000      // 退出阈值（滞回）
FLING_MIN_WIN_D = 90   // 窗口内累计位移下限
FLING_HOLD_MS = 180    // 需连续超过 ENTER 的时长（单帧尖峰不算）
FLING_MIN_TOTAL = 240  // 本次拖拽累计位移下限（原地快抖不算）
// 窗口：250ms 滑动窗口；续期间隔：120ms
```

| 想调什么 | 改哪个 |
|---|---|
太容易晕 | `FLING_ENTER` 1500→1800，`FLING_HOLD_MS` 180→250 |
太难晕 | `FLING_ENTER` 1500→1200，`FLING_HOLD_MS` 180→120 |
要更长的尾迹 | 渲染进程 `enterDizzy(1000)` → 改 1000 |

### 3.4 窗口尺寸限制

```js
MIN_VISIBLE = 120        // 救回底线：至少可见 120px
TOP_OVERHANG = DIALOG_H  // 窗口顶最多出屏 120px：把顶部气泡带让出去，头顶才能贴到屏幕最顶
window 宽高都随倍率缩放：w = 380*f，h = 120 + 520*f
  （只加高不加宽时，>100% 的她会超出画布宽度被裁掉，尾巴先消失）
clampToReachable():      // 可抓取范围
  左右按「她本人的可见包围盒」夹（渲染进程每 250ms 上报 petBox）：
    她的左/右边缘能贴到屏幕左右缘，而不是窗口边缘
  底部至少留 160px
  顶部最多出屏 120px（松手 8px 内吸附到「贴顶」位置，不再是窗口 y=0）
  松手的 leftDock / rightDock 同样按 petBox 算
```

### 3.5 待机与视线

| 项 | 位置 | 默认 |
|---|---|---|
待机首次触发 | `app.js` | 静置 15s |
待机冷却 | `app.js` | 25~50s |
慎用池条件 | `app.js` | 22 点后 或 静置 20 分钟 |
视线增益 | `app.js` `LOOK` | `xGain:28, yGain:22` |

### 3.6 动作调度器（优先级 / 抢占 / 队列）

`app.js` 顶部 `PRIO`，所有动作请求统一走 `playMotion()`：

| 优先级 | 级别 | 来源 |
|---|---|---|
4 | 眩晕 | `TapFace[1]`、甩飞、摇晃 |
3 | 触摸 / 菜单点播 | 耳朵兴奋、尾巴、表情等 |
2 | 剧情 | 双击随机剧情、剧情动作菜单 |
1 | 待机 | Idle 调度 |
0 | 程序 | 召唤等 |

规则：
- 新动作优先级 **更高** → 立即抢占，清空队列；
- **同级** → 排队（队列深度 1），当前动作结束后自动接上；
- **更低** → 直接丢弃。

日志关键字：`motion play / preempt / queue / drop / end / dequeue`。

### 3.7 性能与日志

| 项 | 行为 |
|---|---|
帧率 | 平时：静止 **30fps**，交互（悬停/拖动/菜单）**60fps 持续 6 秒**；节能：**8fps / 25fps**；窗口隐藏时 **停渲染**（`app.ticker.stop()`） |
内存基线 | 每 5 分钟记一行 `[mem] main rss=xxMB` + `[mem] renderer {"heapMB":..}`，长跑对比是否增长 |
日志轮转 | 单份超 **5MB** 自动滚动为 `pet.log.1`（保留上一份）；启动时若超限也会先滚动，不再清空 |
崩溃保留 | `uncaughtException` / `unhandledRejection` / 渲染进程崩溃 → 写 `crash-<时间戳>.log`（含堆栈 + 最近 40 行日志） |

## 四、出问题怎么查

### 4.1 日志在哪

```
D:\dsh\mori-pet\pet.log
```

### 4.2 按现象查关键字

| 现象 | 查什么 | 含义 / 处理 |
|---|---|---|
她不见了 | `[rescue]` | 已自动救回；若无此行，按 `Ctrl+Alt+R` |
窗口越来越大 | `[watchdog] size drift` | 已自愈；频繁出现说明有东西在改尺寸 |
闪烁跳动 | `[watchdog] abnormal bounds` | 尺寸异常，已救回 |
拖不动 | `[ignore] receive` | 有这行说明窗口已接收鼠标；没有就是穿透没关 |
拖不动（续） | `[drag] begin` | 有这行说明按键进来了 |
拖到一半不跟手 | `[drag] resume after idle gap` | 停顿超过 400ms 被兜底收尾后已自动重新接管（正常现象） |
松手位置没生效 | `[main] drag end` 是否紧跟 mouseup | 现在 `drag-end` 有主进程处理，松手即刻收尾并吸附 |
拖歪 / 偏 | `[pet] [drag-unit]` | `screen` 与 `movement` 应接近；ratio 明显不等于 1 说明 DPI 缩放异常 |
拖拽漂移 | `[main] endDrag from ... ->` | 目标 = 按下时窗口位置 + 指针总位移，长拖误差应为 0~1px |
拖拽时宠物上飘/下沉、松手回弹 | 拖拽中窗口是否被撑大（Win32 `GetWindowRect` 对比 380×640） | 正常应恒定；若变大说明 `drag-by` 又退回只调 `setPosition` 了，需用 `setBounds` 连尺寸一起写 |
甩了不晕 | `[fling] enter avg` | 看 avg 是否 > `FLING_ENTER`(1500)，且 fastFor ≥ 180
晕了不停 | `[fling] exit` / `pose reset` | 应等于松手 + 1.0s + 0.4s |
没声音/没动作 | `[pet] motion` | 看 group/idx 是否对 |
参数卡住 | `[pet] pose reset` | 复位是否执行 |

### 4.3 三步急救

```powershell
# 1. 残留进程太多 → 全杀
Get-Process electron -ErrorAction SilentlyContinue | Stop-Process -Force

# 2. 位置/尺寸状态坏了 → 重置
'{"x":1116,"y":272,"size":1}' | Set-Content 'D:\dsh\mori-pet\.userdata\window.json' -Encoding utf8

# 3. 重启
cd D:\dsh\mori-pet
.\node_modules\electron\dist\electron.exe . --no-sandbox --disable-gpu
```

**顺序很重要**：先杀干净再启动，否则会触发单实例锁，新进程一启动就被切换成隐藏。

### 6.1 改完必须做

### 6.2 **禁止**用 PowerShell 读写含中文的源码

2026-10-28 出过一次事故：`Get-Content` 按 GBK 读 UTF-8 文件，
`Set-Content` 写回 → 中文全乱码、部分字符变成 `?`，无法逐字恢复，最后整份重写。

**正确做法**：用 Python 显式指定编码。

```python
s = open(path, encoding='utf-8').read()
s = s.replace(old, new)
open(path, 'w', encoding='utf-8').write(s)
```

### 6.3 改窗口相关代码前先想清楚

| 雷区 | 说明 |
|---|---|
把 `screenX/Y` **逐帧减去窗口位置** | 会形成反馈环（窗口一动读数就变）→ 用「按下点绝对坐标 + 总位移」，窗口位置只在 `beginDrag` 取一次 |
逐帧累加 `dx` 再 `setPosition(b.x + dx)` | Windows 会把 DIP 位置取整到物理像素，每帧漏 ~0.8 DIP，拖几百像素就明显偏离 → 必须用绝对定位，误差不累积 |
按**窗口上边缘**定位 + 高频拖拽 | 拖拽中窗口会被系统逐帧撑大（只调 `setPosition` 时每帧约 +0.8px，实测 640→656×一次快拖）。画布贴底，于是拖着往上走、松手被归一又往下掉 → 每帧用 `setBounds` **连尺寸一起写回标准值**，并按**底边中心**锚定 |
拖拽期间放任 watchdog 纠正尺寸 | 会把锚定好的位置拽回去（视觉回弹）→ watchdog 在 `rendererDragging` 期间直接 return |
两边都管穿透 | 会死锁 → 只让主进程管 |
渲染进程存尺寸 | 与主进程打架 → 唯一真相在主进程 |

## 十一、打包发布

```powershell
npm i -D electron-builder
# 受限环境（%TEMP% 不可写）必须先指到可写目录，否则 NSIS 生成 uninstaller 那步会静默失败
$env:TEMP='D:\dsh\mori-pet\.tmp\t'; $env:TMP=$env:TEMP
npx electron-builder --win nsis --x64
```

产物：

```
dist\mori-pet-1.0.0-x64.exe        86 MB   安装包（含许可页）
dist\win-unpacked\                 绿色版（双击 灵狐召唤器.exe）
```

### 两个坑

1. **许可页中文乱码**：`ATTRIBUTION.txt` 必须是 **UTF-8 带 BOM**，否则 NSIS 按 ANSI 读会变成"钮愔衠葱…"。
2. **NSIS 报 `process failed 2`**：不是编译失败，是 electron-builder 要执行 0.4MB 的 stub 导出 uninstaller，
   而 stub 启动时要用 `%TEMP%`；不可写 → 静默退出 → 整轮失败。设好 `TEMP`/`TMP` 即可。

### 数据目录（打包后）

`%APPDATA%\mori-pet` 不可写时自动退到 **exe 同级的 `.userdata`**（便携模式），再退 `%TEMP%\mori-pet`。

### 签名

目前无证书，安装时会有 SmartScreen"未知发布者"。要消除需买代码签名证书并在 `build.win` 里配置证书。
